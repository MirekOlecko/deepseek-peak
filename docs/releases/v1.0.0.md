First public release of DeepSeek Peak — a native desktop widget and menu bar countdown for DeepSeek API peak/off-peak hours.

### Download

Choose the **DMG** and drag DeepSeekPeak.app into Applications, or download the ZIP. Requires **macOS 13+**, with both **Apple Silicon and Intel** supported by one universal app. Version **1.0.0, build 6**.

### Features

- Full and compact widgets with countdown and a daily timeline.
- Menu bar status, desktop placement and always-on-top options.
- Optional rate-change notifications and launch at login.
- Editable local schedule; no account, API key or analytics.

### First launch

This community release is **ad-hoc signed and not notarized by Apple**. If macOS blocks it, follow **System Settings → Privacy & Security → Open Anyway** after trying to launch it. See [Apple’s instructions](https://support.apple.com/en-us/102445). Managed Macs may prevent this exception.

SHA256SUMS.txt contains checksums for both downloads. The DMG includes installation instructions and the MIT license.

### Verification and accuracy

All 14 schedule tests passed. Both architectures and the app signature were verified; previews ran on Apple Silicon and under Rosetta for Intel. Physical Intel Macs and every supported macOS version were not tested.

The app uses a local schedule, not live billing information. Check [DeepSeek’s official pricing](https://api-docs.deepseek.com/quick_start/pricing/) for current terms. This project is independent and not affiliated with DeepSeek.
